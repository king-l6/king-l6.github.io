Agent Chat Playground:本地向量 RAG 与引用

Agent Chat Playground 是我做的一个可演示的 AI Agent 前端,涵盖 SSE 流式对话、工具调用卡片、本地 RAG。这一版重点是把 RAG 做扎实:文档上传建向量索引,回答末尾带可点击的引用角标,点了能定位到对应文档片段。

为什么强调"引用能点"

很多 RAG demo 只是把检索结果拼进 prompt,回答里看不出哪句来自哪。加上可点击引用,一是让人能核实,二是证明检索是真的命中了,而不是模型自己编的。这是"能信任"和"看起来能用"的区别。

检索这块

本地建向量索引,查询时先 embedding 再算相似度取 top-k。为了让引用准,收紧了 search_notes 的检索:宁可少给几条高相关的,也不要塞一堆低相关的把上下文冲淡。

做下来最大的体会:RAG 的质量不在"检索到没有",而在"检索到的能不能被追溯到"。可追溯性本身就是产品价值。
